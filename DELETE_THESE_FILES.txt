Delete this obsolete file from the backend project after applying the update:

Dockerfile.backup

Reason: the API and database-backup service now use shared build targets in the main Dockerfile. Keeping Dockerfile.backup is unnecessary and can cause confusion.

Optional Docker cleanup AFTER you have confirmed at least one successful Atlas-to-Atlas backup:
  docker volume ls | grep database_backup_archives
If an old volume is listed, remove the exact old volume name with:
  docker volume rm <exact-volume-name>

Do NOT delete migration-backups/ as part of this change. That directory is used only by manual destructive migration safety tooling, not the nightly Atlas backup scheduler.
